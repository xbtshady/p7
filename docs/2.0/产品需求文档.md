# 脑内推演练习 · 产品需求 · 2.0

> 交互细节见 [交互设计文档](交互设计文档.md)；实现约束见 [架构文档](架构文档.md)。

## 1. 目标

练一种能力：**心智模拟**（mental simulation）——没有现成解法可调时，在脑内一步步推，中间状态自己扛，推完倒查。

对立面是**检索**：认出题型就调记忆里的解法。本产品不为刷覆盖率、不为清题库。

**硬规矩**

- 答题期间不展示任何中间结果（推出的真假、计数等）。
- 提交后给出判定；完整推演默认折叠，玩家主动查看。
- 草稿不提供、不禁止、不检测。
- 单题目标时长约 1–3 分钟；随时可停，退出不算作答。

**不做**

3D、剧情、排行榜、社交、每日任务、账号、云同步、连击徽章、讨论区；首版不做棋类残局、结构变换、N-back、账本题型入口。

## 2. 题库（现行）

| 项 | 约定 |
| --- | --- |
| 来源 | 离线导入的 knights-knaves 池，随包 `assets/bank.json`，不联网 |
| 规模 | 约 12000 题；L1–L5 体量约 1000 / 1000 / 2000 / 3000 / 5000 |
| 题型 | 现行库 **仅 `truth`（真假话）** |
| 难度 | 等级只做分组，**无解锁**；人数大致 L1≈3 … L5≈10–14 |
| 约束形态 | 以「唯一合法身份分法」为主，不再以「恰好 k 人撒谎」为题面核心 |
| 可重复 | 做过的题仍可抽到；不排除已答，只避免连续两题同 id |
| 版本 | 带 `schemaVersion`、`bankVersion`；已发布题 id 冻结 |

难度来自推理负担（人数、条件嵌套），不来自题面修辞。L1 也必须能失败。

账本（`ledger`）等题型：**数据协议可保留，产品与 UI 本版不暴露**；有题再开入口。

## 3. 产品形态（对标练习向刷题器）

信息架构四块（参考 LeetCode 的概览 / 题库 / 提交记录 / 题目页，去掉竞赛与社区）：

```
概览  ←→  题库  ←→  记录
              ↓
            题目页
```

- **概览**：进度与能力采样 + 主 CTA「按筛选练一题」。
- **题库**：按难度、状态筛选 + **分页**列表 + 当前筛选下「随机一题」。
- **记录**：全部提交的时间线（只增不改）。
- **题目页**：题面 → 作答 → 提交 → 判定 / 卡点 / 查看推演 → 下一题或重做。

进题路径：概览 CTA、题库点行、题库随机、记录回访。不提供无分页的全量一级列表。

## 4. 题目状态与统计口径

### 4.1 单题状态（题库列表）

| 状态 | 定义 |
| --- | --- |
| 未做 | 该题无任何提交记录 |
| 尝试 | 有提交，且从未 `ok=true` |
| 已对 | 至少一次 `ok=true`（含重做才对） |

### 4.2 概览统计

| 指标 | 定义 |
| --- | --- |
| 各级已对 / 总量 | 该级「已对」题数 / 该级题库题数 |
| 首次正确率 | 近 N 次**该题首次提交**中 `ok=true` 的比例（默认 N=50；不足则按实际条数） |
| 近 7 日 | 提交次数；中位用时（可选展示） |
| 最近提交 | 若干条，点进题目页 |

**首次提交**仍用于衡量真实水平；重做追加记录，不改写历史条。题库状态用「已对/尝试」，与「首次」并存、不互相替代。

## 5. 题型：真假话（本版唯一产品题型）

- **玩法**：N 人各有陈述 + 约束；玩家为每人标定「真话 / 撒谎」，一次填完后提交。
- **不作答**：「撒谎人数」输入框——人数由身份勾选推导，判题以 `answer.truth` 为准；若数据含 `liars`，可由系统自洽校验，不要求玩家另填。
- **答案 / 推演**：每人结论 + `solution.lines`；提交后默认折叠，点「查看推演」展开。
- **卡点**（可选）：保持太多 / 更新跟不上 / 框架没转。答错时展示；答对也可选填。选中即写入该次记录。

## 6. 强度三档（全局，设置或概览可改）

只调节信息与时间压力；**题面默认全程可回看**（长题面下不再用「收起题面」制造难度）。

| 档 | 题面 | 作答 | 时限 |
| --- | --- | --- | --- |
| 宽松 `loose` | 常驻 | 可改 | 无 |
| 标准 `standard`（默认） | 常驻 | 可改 | 无 |
| 挑战 `challenge` | 常驻 | 可改 | 有；按时限归零按错处理并记 `timeout` |

挑战时限建议按级：L1 90s，L2 105s，L3 120s，L4 150s，L5 180s（实现可先用常量表）。

**本版删除**：标准档「开始作答后折叠题面」；挑战档「先写第一步再解锁」。

## 7. 提交与记录

每次提交（含挑战超时自动提交）追加一条：

`{qid, ts, ok, ms, aux, stuck}`

- 退出 / 返回 / 杀进程：不写记录。
- 容量上限与外置路径见架构文档。
- 「下一题」：在当前筛选（难度 + 状态）内随机，避开上一题 id。
- 「重做本题」：清空作答、收起推演、重新计时，再交则追加新记录。

## 8. Demo / 本版范围

- 原生 Android（Java + XML），完全离线，无账号。
- 四入口：概览、题库、记录、题目页；底栏三项 + 题目全屏。
- 强度在设置中修改，立即生效，从下一题起算。
- 不含账本 UI、题型菜单、新手长引导、搜索题干（仅筛难度与状态 + 分页）。

## 9. 相对 1.x 的变更摘要

| 1.x | 2.0 |
| --- | --- |
| 每级约 20 题、truth+ledger 混排 | ~1.2 万题、产品面仅 truth |
| 首页五级 → 全量列表 | 概览 + 分页题库 + 记录 |
| 进度 = 已做题号数 / 总量 | 已对 / 总量 + 首次正确率 |
| 列表显示首次对/错 | 列表显示未做/尝试/已对 |
| 作答含撒谎人数；标准档藏题面 | 只标身份；题面常驻 |
| 提交后直接摊开答案 | 默认折叠，查看推演 |
