# 脑内推演练习 · 产品需求 · 2.0

> 交互细节见 [交互设计文档](交互设计文档.md)；实现约束见 [架构文档](架构文档.md)。修订 **2.0.1**。

## 1. 目标

练一种能力：**心智模拟**（mental simulation）——没有现成解法可调时，在脑内一步步推，中间状态自己扛，推完倒查。

对立面是**检索**：认出题型就调记忆里的解法。本产品不为刷覆盖率、不为清题库。

**硬规矩**

- 答题期间不展示任何中间结果（推出的真假、计数等）。
- 提交后给出判定；完整推演默认折叠，玩家主动查看。
- 草稿不提供、不禁止、不检测。
- 单题目标时长约 1–3 分钟；随时可停，退出不算作答。

**不做**

3D、剧情、排行榜、社交、每日任务、账号、云同步、连击徽章、讨论区；首版不做棋类残局、结构变换、N-back、账本题型入口。

### 1.1 指标边界

概览中的正确率、提交次数、用时、卡点等是**表现采样**，用于自我对照，**不作为「能力已提升」的因果证明**。须能区分（至少在数据上可派生）：首次接触、重复作答、未见过的新题（定义见交互设计 §1.3）。完整迁移/延迟再测方案不阻塞本版交付。

## 2. 题库（现行）

| 项 | 约定 |
| --- | --- |
| 来源 | 离线导入的 knights-knaves 池，随包 `assets/bank.json`，不联网 |
| 规模（现状） | 约 12000 题；L1–L5 约 1000 / 1000 / 2000 / 3000 / 5000。**规模是现状描述，不是首要成功指标** |
| 题型 | 现行库 **仅 `truth`** |
| 难度（现行启发式） | 等级只分组、无解锁；**主要按人数**落入 L1≈3 … L5≈10–14。人数≠推理负荷；复杂三人或易解多人已知局限，须抽样校准（见 §2.1） |
| 约束形态 | 以「唯一合法身份分法」为主 |
| 可重复 | 做过的仍可抽到；只避免连续两题同 id |
| 版本 | `schemaVersion`、`bankVersion`；已发布题 id 冻结；改内容须换新 id |

账本等题型：协议可留，本版 UI 不暴露。

### 2.1 题库质量门槛（优先于扩量）

入库/发版前应满足（细节与自动化程度见架构 / 导入脚本）：

| 门槛 | 要求 |
| --- | --- |
| 唯一解 | 枚举验证恰好一组自洽解，且与官方解一致 |
| 解析一致 | `solution` 与 `answer.truth` 不矛盾 |
| 结构合法 | 字段与校验见架构 §3.3；`liars` 与 truth 不一致 → **丢弃该题** |
| 近重复 | 须有检测策略（可先哈希题面结构 / 规范化台词）；不通过则不得充当「新题」扩量 |
| 语言 | 中文人名与句式可读；抽检无严重病句 |
| 难度 | 每级抽样人工或半自动复核；挑战时限为**初值待校准** |
| 来源与许可 | 记录数据集名称与使用条件（随仓库或发布说明） |

未过门槛的题不得因「凑规模」强行保留。

## 3. 产品形态

```
概览  ←→  题库  ←→  记录
              ↓
            题目页
```

- **概览**：进度与表现采样 + CTA；**设置（强度）唯一入口在概览右上角**。
- **题库**：难度×状态筛选 + 分页 + 随机。
- **记录**：Attempt 时间线；点入 = **重做该题**，不是当次提交只读审阅。
- **题目页**：作答闭环。

## 4. 题目状态与统计口径

### 4.1 单题状态（题库）

| 状态 | 定义 |
| --- | --- |
| 未做 | 无提交 |
| 尝试 | 有提交且从未 ok |
| 已对 | 至少一次 ok |

### 4.2 概览统计

| 指标 | 定义 |
| --- | --- |
| 各级已对 / 总量 | 该级已对题数 / 该级题库题数 |
| 首次正确率 | 见下算法；默认窗口 N=50 |
| 近 7 日 | 提交次数；中位用时可选 |
| 最近提交 | 若干条，点进题目（重开作答） |

**首次正确率算法（与架构一致）**：

1. 对每个出现过的 `qid`，取时间最早的一条记录作为该题的「首次记录」。  
2. 将这些首次记录按 `ts` **降序**排列。  
3. 取前 N 条（不足 N 则全取），计算 `ok=true` 的比例。  
4. **每题最多计入一次**。

重做追加记录，不改写历史条；不改变「首次记录」本身。

## 5. 题型：真假话

- 为每人标「真话 / 撒谎」后提交；**不**另填撒谎人数。
- 推演默认折叠。
- 卡点三项：展示但不强制选择（详见交互设计）。

## 6. 强度三档

**仅在概览 → 设置中修改**；立即写入，从下一题起生效。

| 档 | 题面 | 作答 | 时限 |
| --- | --- | --- | --- |
| 宽松 | 常驻 | 可改 | 无 |
| 标准（默认） | 常驻 | 可改 | 无 |
| 挑战 | 常驻 | 可改 | 有（初值按级，待校准） |

**挑战档为可选压力模式**，不是使用产品的必要条件。

本版删除：藏题面、第一步门禁。

## 7. 提交与记录

`{qid, ts, ok, ms, aux, stuck, bankVersion}`（`bankVersion` 为写入时题库版本，见架构）。

- 退出不算作答。
- 容量与截断语义见架构。
- 下一题 / 重做规则见交互设计。

## 8. Demo / 本版范围

- 原生 Android，离线，无账号。
- 不含账本 UI、题型菜单、搜索题干、提交只读回放。

## 9. 相对 1.x

| 1.x | 2.0 |
| --- | --- |
| 小池混排 | 大池 truth；质量门槛优先于规模叙事 |
