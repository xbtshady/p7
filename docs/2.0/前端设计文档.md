# p7 前端设计 · 2.0

> 布局、视觉与文案表。**用户流程、状态机、边界与验收**见 [交互设计文档](交互设计文档.md)。修订 **2.0.1**。

单 Activity 切布局，锁竖屏，无自定义动画。底栏三页 + 题目全屏页。强度修改**仅**在概览设置中。

## 1. 导航

```
[ 概览 ]  [ 题库 ]  [ 记录 ]     ← 底栏；题目页隐藏底栏
```

- 默认落在 **概览**。
- 从题库 / 记录 / 概览 CTA 进入题目页；返回回到来源页（题库保留筛选与页码）。
- 设置：概览右上角文字按钮。

## 2. 概览 overview.xml

| 元素 | 内容 | 行为 |
| --- | --- | --- |
| 标题 | 应用名 | — |
| 设置 | 「设置」 | 弹 Dialog：强度三档 + 版本只读行 |
| 已对总数 | 整数 | — |
| 分级条 ×5 | `L1`…`L5` + 进度条或 `已对/总量` + 副文案人数（如「约 3 人」） | 点击 → 题库并预设该难度筛选 |

| 最近提交 | 最多 10 行：时间、题号、对/错 | 点行进该题 |

不显示：连对数、徽章、热力图、每日任务。

## 3. 题库 bank.xml

**筛选行**

- 难度：全部 / L1 / L2 / L3 / L4 / L5（单选芯片或下拉）
- 状态：全部 / 未做 / 尝试 / 已对

**操作**

- 通栏按钮「随机一题」：在当前筛选结果中抽一题（池 >1 时避开 `lastQid`）；池空则置灰。

**列表**

- 原生列表，**每页 30 行**；底部分页：上页 / 页码 / 下页。
- 顺序 = 当前筛选下，保持 `bank.json` 数组相对顺序。
- 行高 56dp：

```
L2-T1-0183    4人     已对
L2-T1-0184    4人     未做
L2-T1-0185    4人     尝试
```

- 左：题号（13sp 次要色，等宽若可得）
- 中：人数（如 `4人`，16sp）
- 右：状态文案（未做灰 / 尝试次要色 / 已对绿）
- 整行可点 → 题目页

空筛选：居中「没有符合的题目」，随机置灰。

## 4. 记录 history.xml

- 全部提交，新→旧。
- 行：`日期时间  题号  对/错  强度`；挑战超时可标「超时」。**不展示耗时**（标准档无跑表，不假装有精确用时）。
- 点行 → 题目页（该 qid）**新开空白作答**（重做入口，非该次提交只读回放）。
- 首版不做筛选；列表过长则同样分页（每页 50）。

无记录：居中「还没有提交」。

## 5. 题目页 question.xml

```
[顶部]  题号 · 强度名              [计时?] [关闭]
[题面区]
[作答区]
[提交]
[结果区]     仅提交后
[推演区]     仅点开后
```

### 5.1 顶部

- 左：`{id} · {强度名}`
- 中右：挑战档显示倒计时 `mm:ss`，≤10s 变错色
- 右：「关闭」→ 回来源页，不写记录、不确认

### 5.2 题面

每人一行 `名：台词`；约束独立一行加粗。题面**三档均常驻可滚动回看**。

### 5.3 作答

每人一行，并排「真话」「撒谎」单选。  
**无**「撒谎人数」输入。  
未填满时提交仍可点（交白卷按错，`partial`）。

人多（≥7）：作答区随页滚动，可两列紧凑，语义仍为每人显式二选一（未选 ≠ 默认真话）。

### 5.4 提交后结果区

1. **判定**：`对` / `错`（大字，绿/红）。不显示分数；不展示耗时。
2. **查看推演** / **收起推演**：按钮切换；默认收起。
3. **下一题** | **重做本题**
4. **提交**键：进入结果区后**隐藏**（勿把提交键改成重做）。

**不做**：卡点自报（「这题卡在哪」三选一已删除）。

挑战超时：按错处理；作答区锁定保留已填；结果区按钮集合与上相同（下一题 + 重做）；推演规则同普通错题。

### 5.4.1 本题提交

题目页底部「本题提交」：该 `qid` 的 Attempt 列表（新→旧，最多 50），行含时间、对/错、强度；**不**展示耗时、**不**还原当时勾选。无记录则整块隐藏。进入作答与每次提交后刷新。

### 5.5 推演内容（truth）

标题「推演」。一行每人结论 + `summary`，再跟 `solution.lines` 分段。

## 8. 视觉规范

- 浅色固定，不跟随系统深色；方向为**墨色练习纸**（冷灰纸底 + 深青墨），避免默认蓝白 demo 感
- 颜色：纸底 `#EDEEEA`，表面 `#F7F7F4`，正文 `#1A211C`，次要 `#5A635C`，强调 `#1E4D45`，对 `#2F6B45`，错 `#A33B32`
- 字号：题干/大判定 20sp，正文 16sp，次要 13sp，行高 1.5
- 间距：左右 16dp，区块 24dp，行内 8dp
- 控件：按钮高 48dp、圆角 8dp；真/假方框选中填强调色
- 不加：自定义动画、插画、图标字体依赖

## 9. 边界

| 情况 | 处理 |
| --- | --- |
| 题库加载失败 | 概览全屏提示，底栏可进但题库/随机不可用 |
| 筛选为空 | 见 §3 |
| 数字/非法（若残留控件） | 视为未填 |
| 推演很长 | 整页 ScrollView，推演不单独套一层滚动冲突 |
| 旋转 | 锁 portrait |
| 返回键 | 题目 → 来源（见交互设计导航表）；其余底栏页 → 再按退出 app |

## 9.1 无障碍抽测（与交互设计 §10 对齐）

- 默认标准档可完成主路径；挑战非必需。  
- 系统字体放大下题面/作答可滚达提交。  
- 倒计时依赖数字不只靠变色。

## 10. 相对 1.1 前端的废止项

- `home` 五级进全量 `list` 的两级结构  
- 列表题型列、首次对/错列、列表顶「点题可重做…」  
- 标准档收起题面、挑战档第一步输入  
- 撒谎人数框、账本数字作答与账本答案表  
- 提交后强制展开「答案」
